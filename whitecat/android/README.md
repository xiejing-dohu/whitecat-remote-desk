# 白猫 Android App

## 设置与本机存储（0.9.1）

点底部「我的」直接打开独立的设置页，返回键回到原标签。首页用于查看当前服务器、选择执行 Agent 和进入会话。服务器管理、地址与配对、字体与背景、配置教程、应用信息及输入与同步均在设置内。

「应用信息与本机存储」显示已安装版本、内部版本号、包名、Android 版本和 API 级别。可复制会话与设置目录、应用文件目录和临时缓存目录。路径由当前 Android 用户的应用上下文提供。页面会读取偏好文件的实际占用，包括会话缓存、草稿与设备设置。Android 的应用私有目录受系统访问控制；换机可在「迁移」页选择要导出的内容。

「设置 → 服务器管理」保存多台移动网关及其本机名称。每台服务器单独配对，保存自己的会话、草稿、待发请求和执行 Agent 选择。点底部「Agent」可查看当前服务器上的执行节点，点节点后进入其聊天列表。管理员在服务器本机网页的「设置」中添加执行 Agent，并用生成的配置启动 worker。[服务端配置说明](../deploy/agents.md)

### 进入、外观与配置教程

冷启动时先显示白猫进入页，已配对可进入工作台或上次的聊天。首次使用点「首次连接」，可在配对表单中打开「设置 → 配置教程」，返回后继续填写。从后台切回继续当前页面。有尚待回执的任务会自动恢复到原会话并沿用原编号。

在「设置」中点「字体与背景」。四档字号分别为系统字号的 90%、100%、115% 和 130%。背景有曜石、深海、暖纸三种，正文、卡片、输入区和系统栏随选择更新。设置保存在本机，重启保持；「恢复默认」切回标准字号与曜石背景。

在「设置」中打开「配置教程」。本机教程说明如何启动服务、设置 USB 转发和生成配对码。远程教程说明在指定主机启动 Codex worker，通过移动网关使用 HTTPS，并支持手动填写地址。点步骤标题展开命令，点命令即可复制。点「填写配对信息」将地址带入表单，成功配对后才切换工作站。

曾同步的会话由同一工作站确认删除后，首页、会话列表和聊天页会显示「远程已删除」。缓存正文和草稿仍可查看。远程已删除会话只读，用户仍可从本机移除。短暂断网、普通代理 404 或服务端 503 会保留缓存；原生历史不可用、工作站身份待核实均有单独提示。

## 工作台与换机

底部导航有「首页、会话、Agent、迁移、我的」五个标签。首页展示工作站连接、会话数量和最近会话。新建会话时可选择角色，也可以在「Agent → 聊天角色模板」中新建、编辑或归档角色。每个自定义角色拥有自己的名称与指令，由同一台已配对的 Codex 工作站执行。会话保留创建时的角色配置，之后编辑或归档角色，原会话仍能照常追问。

在会话列表点「…」或长按会话，确认「仅本机删除」后，本机清除该会话的缓存、草稿与列表项。该安装会记住删除选择，重启和同步后继续隐藏。重新安装或清除应用数据会清除这个选择。服务器、原生 Codex CLI 和其他手机保留会话；有待确认发送的会话须先处理完该次发送。

换机前，两台设备先分别配对同一移动网关。在旧手机「迁移」中选择当前或全部已缓存会话，并勾选会话记录、草稿和偏好中的所需项目。新手机可使用相机扫描或从相册读取二维码，核对摘要后点确认。二维码五分钟有效，仅一台接收设备可领取；导入保留接收机已有草稿、设置与较新历史。传输使用 AES-GCM 加密，解密密钥随二维码交给接收机。设备凭据、待发送任务和本机删除记录均排除在迁移范围之外。

## 安装与首次配对

1. 在手机上打开 APK，或在已授权 USB 调试的电脑上运行下方安装命令。日常使用只需安装 `白猫.apk`。
2. 在电脑上启动白猫 [API 与 Codex 工作站](../README.md)。另开一个终端，在 `whitecat` 目录运行移动接入服务。如该服务已运行，直接生成配对码。
3. 使用 USB 时，把手机的 18744 转发到电脑的 18744。打开 App，保留默认服务地址 `http://127.0.0.1:18744`，输入工作站生成的一次性配对码。配对码 10 分钟内有效，兑换一次后失效。App 使用 Android Keystore 保护设备凭据。
4. 配对成功后进入首页。看到「工作站在线」后点「新建会话」，也可在 Agent 页选定节点再开始。历史在底部「会话」页。打开会话后可展开工作站活动，在底部输入框继续追问。

```powershell
# 在 whitecat/android 目录，adb 来自 Android SDK Platform-Tools
adb install -r ".\白猫.apk"
adb reverse tcp:18744 tcp:18744
```

```powershell
# 在 whitecat 目录分别运行。配对码只显示在自己的终端。
python -B mobile_gateway.py serve
python -B mobile_gateway.py pair
```

连接多台设备时，在 adb 命令中用 `-s 设备序列号` 指定手机。USB 线重新连接或设备重启后，可能需要再次运行转发命令。

**无线接入。** 将移动接入服务部署在手机能到达且证书受 Android 信任的 HTTPS 域名上。也可让已有 HTTPS 反向代理仅转发本机 18744 移动入口。App 的服务地址填域名和端口，重新配对。移动接入服务原生支持 `serve --bind 私有网卡地址 --port 端口 --cert 证书链路径 --key 私钥路径`。工作台管理端口 18742 保持本机访问。此次设备验收使用 USB 等效的 ADB 转发，无线网络部署须按使用环境验证。

## 断网后继续

App 先将完整正文、文本附件、目标会话和随机命令编号写入应用私有存储，再发送任务。出现「未收到回执」时，点「按原请求重试」。重新打开 App 后，这个按钮仍对应同一请求。已有回执时后端返回原任务编号。可点击加号选择 UTF-8 文本文件（最大 32 KB）。已打开会话的运行结果保存在本机，可在断线时回看。

## 继续工作站原生 CLI 会话

在会话列表中搜索工作站首条提问，打开后可继续输入。连接共享 daemon 时，终端保持打开即可从手机发送；两端提交的消息在同一原生线程排队。要在终端继续手机的追问，打开聊天页的工作站设置，复制该会话的 `codex resume` 命令。打开共享线程时，原生 CLI 的可见进度与回复会实时出现在当前聊天。离线时可查看缓存、编辑草稿或点发送；待发请求在重连后按原编号自动发送。
